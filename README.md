# 古籍异文校勘与版本关系工作台

这是一个服务数字人文研究者的 Go 全栈应用，用来整理不同传本的卷册坐标、段落摘录、字词异文和底本候选。系统采用分片文档存储：每个摘录按文本摘要写入内容寻址目录，修订会产生新的文本块，不覆盖原始记录。校勘页面使用 Go 模板渲染，浏览器再通过 JSON API 增量读取数据。

传本、定位、摘录、异文、规则版本和分歧卡片是核心对象。定位必须同时包含卷、叶、行、字位；异文区分增衍、脱文、倒文、通假和形近；底本候选依据文本相似度、传本优先级和同卷关系评分。规则版本发布后只作用于新的对齐批次，历史候选保留规则指纹。

## 启动

```bash
go run ./cmd/collation
```

默认监听 `:18102`，可用 `CODEX_ADDR` 和 `CODEX_SHELF` 修改地址与分片文本根目录。首页为 `/`，健康检查为 `/healthz`。

## 全栈冒烟

1. 打开首页，确认传本、段落和分歧列从真实 API 加载。
2. `POST /api/codex/witnesses` 创建两个传本，记下传本 ID。
3. `POST /api/codex/passages` 提交完整卷叶行字定位，确认返回 `digest`。
4. `POST /api/codex/collations` 启动分片对齐，再读取 `/api/codex/tasks` 与 `/api/codex/divergences`。
5. `GET /api/codex/summary` 检查分片文本架与校勘对象数量。

本项目不包含测试文件；`go test ./...` 仅作为生产包编译检查。
